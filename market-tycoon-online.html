สร้างอาณาจักรธุรกิจแผงลอย เล่นออนไลน์กับเพื่อนได้เลย!

⚠️ ยังไม่ได้ตั้งค่า Firebase

เกมนี้ต้องใช้ Firebase (Firestore) เพื่อซิงค์ข้อมูลระหว่างผู้เล่นแบบเรียลไทม์

1. เปิด Firebase Console → สร้างโปรเจกต์ (หรือใช้โปรเจกต์เดิมที่มีอยู่แล้ว)
2. เปิดใช้งาน Firestore Database (โหมดทดสอบ/test mode พอสำหรับเล่นกับเพื่อน)
3. คัดลอกค่า firebaseConfig จากหน้า Project settings
4. แก้ตัวแปร firebaseConfig ที่ต้นไฟล์ HTML นี้ด้วยค่าของคุณ แล้วบันทึกใหม่

โค้ดส่วนเกมทั้งหมดพร้อมใช้งานแล้ว รอแค่เชื่อม Firebase ของคุณเท่านั้น
